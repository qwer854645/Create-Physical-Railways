# 工程师护目镜

驾驶台、铁路对接连接器及原生轨道连挂器的物理操作提示，统一通过
`GoggleText.add` 调用 Create 的 `LangBuilder.forGoggles`，按当前字体宽度为护目镜图标
预留原生缩进。不能直接向护目镜列表加入无缩进正文，也不能靠删除首行规避重叠。

驾驶台读取服务器同步的 `VisualBound`、已安装时刻表和 `VisualStatus`：未绑定只显示
未绑定提示；已绑定默认显示绑定、手动/时刻表及状态原因三行，方便操作时快速查看。
潜行时附加名称（非空时）、方向与档位、两行操作帮助，最多七行。客户端不能通过
`DriverControls.body` 判定绑定，该查询只返回 `ServerSubLevel`。
绑定信息只说明驾驶台位于物理车体上，不代表车体已安装转向架或能够行驶。

连接器的空手右击信息在服务端生成，经 `addInformation` 共用正文；不能调用护目镜
格式化方法，因为 Create 的 `forGoggles` 需要客户端字体。

自动检查：`checkGoggleInformation` 覆盖状态文案键、客户端绑定查询边界、三个提示入口
使用原生缩进及服务端聊天分离；`checkLanguage` 检查语言资源，`build --offline` 全量回归。

待游戏内验收：

- 中英文及不同 GUI 缩放下，查看驾驶台、铁路对接连接器和物理连挂模式的轨道连挂器，首行与图标不重叠。
- 驾驶台放在地面/物理车体上，分别查看未绑定、手动、装入时刻表以及潜行状态原因；退出重进后保持正确。
- 空手右击对接连接器，确认聊天正常且日志没有客户端字体访问异常；原版连挂器非物理操作模式保持原生提示。

离线检查不代表画面验收通过；客户端只在用户明确请求时启动。
