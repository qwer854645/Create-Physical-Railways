# 牵引分配（0.1.61）

本次客户端日志显示：一列总计三副转向架，只有一副 256 RPM 供能，P8 目标 25.6 格/秒，实际速度逐渐停在约 4.5 格/秒。动力架承担质量 111.5，另两副分别为 111.5、103，总计约 326

旧规则将动力架出力限制为 min(256×6, 111.5×2.5)=278.75，另外两副无动力架在正牵引时仍分别按自身分担质量施加 0.6 格/秒²滑行阻力。扣除这部分阻力后，整列剩余加速度仅约 0.46 格/秒²，尚未计入 Sable 自身阻尼及接触损耗

现在先按车钩连接图计算编组，去重计入车体质量，加上每副转向架自身质量。共享车体不重复计重，连挂但未装转向架的车体也计入。未通动力、已制动或已脱轨的转向架不分配牵引预算

设编组总质量 M，动力输入权重 w_i=abs(RPM_i)，则动力架的加速分配质量为 M_i=M×w_i/Σw。实际出力仍以 min(abs(RPM_i)×forcePerRpm, M_i×maxAcceleration) 为上限，并随目标速度误差收敛；自动驾驶的牵引档仍可按既有出力比例缩放。没有直接设置前进速度或位置

按本次日志的编组，单动力架的加速预算改为 min(1536, 326×2.5)=815。正牵引指令下，无动力架随行；空挡、整列断动力、停车保持、服务制动和紧急制动仍按原规则生效。超出实际 RPM 牵引预算的重载仍会降低加速度，输入为零的转向架不会获得额外动力

应力仍按各安装座分担的质量计算，本次不改变应力系数、最高目标车速、配置的加速度、制动力或物理体数量。原有 Sable 阻尼与接触损耗仍存在，因此控制模型能给出的加速度不等于游戏内必然达到的数值

日志新增 tractionMass（分配给该动力架的整列加速质量）与 commandedForce（上个物理步两端平均纵向指令力），supportedMass 继续表示本架自身承担质量，供区分牵引上限、制动和轨道停车限制

## 客户端验收

1. 同车体两副，一副接 256 RPM、另一副断动力，比较空载与逐步加载后的 P8 直线起步
2. 用车钩再连一节无动力车，检查加速是否仍明显改善，正反向均测试
3. 增加第二副动力，或将输入改为 64 RPM，确认动力架数量和 RPM 仍影响重载牵引能力
4. 空挡滑行、全部断动力、B1/B4 和紧急制动，确认无动力架仍参与减速，停车不反向
5. 最高档接近目标速度后收敛；再回归时刻表起步、自动入站、信号停车和解除连挂

自动检查覆盖纵向控制和分配公式，真实关节求解、接触损耗及驾驶手感等待客户端观测
