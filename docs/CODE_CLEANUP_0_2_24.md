# 0.2.24 旧实现清理

日期：2026-10-21

## 检查范围与依据

检查 197 个生产 Java 源文件、Mixin 注册、模型引用、构建配置和测试入口。使用 javac 语法树及符号解析区分具体重载的生产调用，另外检查只写不读字段；文本搜索用于核对反射、Mixin、资源引用和测试。分析脚本与完整日志保存在本机 build，不进入发行包。

未按名称出现次数盲删：原生 Train / Navigation / ScheduleRuntime 的只读保护重写、NeoForge 事件入口、可选模组 Mixin、接口实现以及碰撞几何采样辅助仍有必要。默认车型是无可选模组环境的有效实现，不是历史迁移代码。

## 已删除

- TrackNetwork 的无调用旧重载、全路径查询入口及未使用的向量转换
- 单一默认车型的查找 / 碰撞 / 包围盒重载，以及放置规划的统一车型尺寸快捷入口；当前使用具体款式和逐转向架尺寸
- 旧的无 planned 参数选岔提交入口，测试改用现行 preview / commit 流程
- ConsoleElection 内重复构建连挂连通分量的入口及其 Link 类型，测试改为和运行时一样调用共享 ConsistGraph 后选举
- 牵引函数中不带实际牵引质量 / 整列供电状态的旧重载，测试显式提供当前参数
- 旧驾驶台最高速度换算函数，测试转向现行配置比例显示换算与绝对档位限速
- 旧统一车钩闭锁判断及固定长度常量，测试使用当前 CouplerMechanism 按车钩类型判断
- 不再调用的身份协调快捷入口、车钩对端快捷查询和货物 bound 查询
- 旧统一平台高度派生常量，测试与运行时共同读取款式目录中的平台 / 枢轴数据
- 驾驶台只写不读的 previousReverser，以及 NativeTrainContacts.Frame 未使用的世界引用和对应构造参数

第一批共删除 28 个方法。与清理前语法树对照，保留的 1,274 个方法内容相同；第二批仅移除上述两个不可读状态字段及对应赋值 / 传参，没有改变碰撞计算或驾驶参数。

183 个本模组模型均可从物品模型、方块状态及模型依赖追溯，没有删除仍被间接引用的外观资源。测试几何采样辅助保留；本次不宣称自动证明不存在任何冗余或外部动态引用。

## 验证与限制

完整离线 build 及其全部 check 任务通过，独立 signalValidation 源集另外编译通过。本轮不运行服务端，不启动客户端。速度、制动、车钩间距、款式尺寸、配置键和存档字段保持现有语义；用户实际驾驶手感未在本轮重新验收。

客户端有机会回归时，重点观察单车 / 连挂牵引、换向及驾驶台动画、弯道选岔、车钩闭锁和重新上轨。现有服务端混跑测试此前的通过记录保留，本次仅核对其编译兼容。
