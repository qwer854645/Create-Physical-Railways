# 标准平台高度

版本：0.2.0 · Create 6.0.10-280

## 高度基准

以水平 Create 铁轨所在方块的底面为 Y=0。已核对锁定版本 `ITrackBlock.getConnected` 使用方块底面中心加中心抬升量，水平轨道抬升量为 0；不是把可见轨头顶面当作 Y=0。

- 转向架中心：Y=0.983910375，保持轮子模型与轨面原有关系
- 安装座方块底面：Y=1
- 平台板底面：Y=1.75
- 平台板顶面：Y=2，平台上搭建的方块从这里开始
- 平台比旧版升高：0.391089625 格

`BogieGeometry` 集中定义高度。上部车体中心与转向架中心的距离从 0.125 调整为 0.516089625 格，转向架侧枢轴锚点相应从中心上方 0.375 调整为 0.766089625 格。平台侧锚点仍在安装座方块内 Y=0.75。

下方支座延伸到安装座方块内 Y=0.358910375，上端接平台底面，使用原有 Create 暗色金属材质。碰撞形状为平台板加中央支座，不增添方块或独立物理体；顶部应力输入保留。

新放置、物理体底部安装和扳手重新上轨共用同一高度关系。坡道上沿局部上方向保持支承间距，不对世界 Y 做逐帧取整；坡道或倾斜车体不保证与世界格网对齐。水平弯轨虽保持相同标高，朝向和横向位置仍随曲线变化，对接建议使用水平直轨。

## 当前格式

仅按当前几何目录计算平台及枢轴高度，不再保存、读取或迁移 MountHeightVersion。不同 Railway 款式的平台标高由 BogeyVariant.mountTop 确定，均为整数格。上文数值对应独立运行时的默认款式。

重新上轨仍会先验证全部安装座、轨道与空间，再以事务移动整节车体及转向架；失败时恢复全部已尝试的位姿和速度。0.2.0 不保证旧版已放置车辆可用。

## 客户端测试场景

1. 在不同整数高度的水平直轨上新放转向架，平台顶面应与轨道方块底面上方 2 格对齐；在平台上搭建方块，与世界同高度方块比较
2. 两端安装朝向相对的对接连接器，按连接器要求设置间距，停车后测试世界端配对、锁定、物品/流体交换及解除后发车。高度标准化不代替连接器的朝向与间距要求
3. 给既有物理体底部安装新转向架，再重新上轨，检查车体高度、轮子贴轨和应力输入
4. 同车体两副或更多转向架，上轨后整车保持同一网格高度；检查过弯、坡道衔接时支座、模型和物理关节无拉扯
5. 当前版本新建车辆退出重进或重复上轨，高度不应累加
6. 粘合/拆分安装座所属车体后重新上轨；空间不足、轨道不足或支承尚未恢复时不得部分移动
7. 检查支座外观、准星选框、玩家碰撞与顶部接轴；水平轨道上轮子不悬浮、不陷入轨道

`checkPlatformHeight` 检查不同高度/朝向的整格平台位置、多转向架上轨、旋转车体底部安装、支座模型尺寸及轮轨高度保持，并运行已有碰撞、放置、语言和完整构建检查。客户端对接效果与本次重构回归仍待实际验收。
