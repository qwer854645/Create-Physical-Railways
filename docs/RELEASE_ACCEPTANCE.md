# 0.2.25 发布前验收

日期：2026-11-09。范围为当前工作树与重新构建的发行 JAR。此记录只证明列出的离线检查；不替代真实存档、多人和性能测试。

## 本轮发现与处理

设置页“对准停车点”按钮的指令被服务端菜单拒绝，实际点击无效。按用户要求取消整个功能，清除按钮、指令、控制状态、同步字段、挪车决策器和专用测试。停车点偏差显示及正常时刻表停站逻辑保持原用途。

## 离线验收

- 修改前与修改后分别运行 `gradlew.bat clean build --offline`；包含语言、资源、纯逻辑、真实 NBT 往返及字节码调用契约检查。
- 转向架归属与搬移：47 项，覆盖版本保存、副本先加载、归属拒绝与交接。
- 车钩生命周期：35 项实际 NBT、配对、连续搬移与回调契约检查。
- 生命周期回放：10,729 项，覆盖分阶段加载、路线、拆分、重连与车站；这是离线回放，不是真实世界驾驶。
- 移除对齐后的驾驶台意图：28 项；中英文各 402 键，4,435 项语言断言。
- 135 组转向架目录、来源哈希与保存索引检查通过。
- 原生车钩资产：25 种模型、机械分组与纹理契约通过；对接几何和 140 种硬件碰撞变体检查通过。
- 货运兼容：对当前开发安装的 Simulated、Hose、Automated Logistics 和 Railway 检查 45 个真实发布包接口签名通过。
- 修改后清理构建成功，121 个任务全部执行。BnB/CEE 另有 15 个发布接口、Railway Beta 另有 21 个发布接口及资源检查通过。
- 发行 JAR 的 740 个条目通过 ZIP 完整性、模组元数据、MIT 许可证、十一页思索、最新工具贴图、Mixin 类存在性、可选模组代码未打包和对齐控制器已移除检查。
- 本轮包 SHA-256：`3ad8b9f09fd446396a32843751fb05b97e9c12f580fd2aa636887f56777ceefd`。

## 尚不能判定通过

1. 真实世界中的保存重进、车尾区块延迟加载、搬移中退出，以及拆除后同位置重建。重点观察物理关节、配对和时刻表恢复。
2. 从造车到连挂、手动驾驶、岔路预选、红灯、停站装卸再重进的完整闭环；多节车厢倒车过岔也需覆盖。
3. 两名玩家抢拉杆、玩家断线、服务端重启和主从驾驶台恢复。
4. 干净正式安装实例的最小依赖启动、可选模组缺席和运行时 Mixin 应用；本轮接口检查不能替代启动验收，也没有重新跑所有旧版依赖组合。
5. 多车长时间运行的帧时间、服务器 tick 和内存曲线。本轮没有运行时采样，不能确认卡顿已消除。
6. 十一页思索的实际回放、指针位置、可读性与物品持握显示。

## 发布判断

离线检查可作为候选测试包依据，尚不足以宣布稳定版验收完成。实机项目通过后可先公开 Alpha，并按实际验证范围描述可选兼容。

安装说明必须标注 Minecraft 1.21.1 / NeoForge、Create 与 Sable 依赖；不支持物理列车跨维度行驶。命名空间已直接改为 `physicalrailways`，不提供改名前旧存档内容迁移。
