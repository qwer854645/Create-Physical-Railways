# Railway 分型车钩（0.1.56）

## 机械依据

加拿大运输安全委员会对自动车钩的调查说明了钩舌从开放到闭合、锁件落下后的闭锁过程：[R17V0096](https://www.bst.gc.ca/eng/rapports-reports/rail/2017/r17v0096/r17v0096.html)。英国 RAIB 的 London Gateway 报告对比了螺旋连挂、侧缓冲器及受压时的接触：[报告 14/2023](https://assets.publishing.service.gov.uk/media/66617a9816cf36f4d63ebed7/R142023_231219_London_Gateway.pdf)。AAR 的耦合系统规范范围见 [Coupling System & Truck Castings](https://aar.com/standards/coupling-system.php)。本实现没有按模组外观名称认定某一具体 AAR 标准型号。

以下长度、时间、速度、松量是游戏尺度参数，不是现实标准值或承载认证。

## 分型逻辑

- 本模组原车钩：保持旧的立即连挂、双向缓冲与原模型，不改变已有驾驶手感
- LINK / LINKLESS：连接工具触发约 1 秒的抬销、送环、落销，销落下后才建立拉向约束；只承受拉向作用，不用径向弹簧推车，钩体接触承担压缩。LINKLESS 没有附带环，工具操作中显示一个取自 Railway 原模型的连接环，不新增耗材系统
- KNUCKLE / KNUCKLE_SPLIT：连接工具触发约 0.6 秒的闭合钩舌、内部落锁，闭锁后建立双向缓冲。Split 用原模型的分段钩舌，同一闭锁原理，不凭名称另造一种机构。行驶中两钩头共用对接轴和平均上方向，钩柄在固定安装座内显示小幅伸缩，不锁定连挂时的车体角度
- SCREWLINK：约 2 秒完成挂环和旋紧，挂环后可受拉，随螺杆动作逐步收掉 0.15 格安装余量。只拉不推，压缩靠另装的缓冲板和正常实体碰撞传递；不要求玩家满足严格的缓冲板装配清单

原有连接工具与不同类型禁止互连的规则保持。全部连接仍由工具或轨旁连挂器主动发起，本轮不增加靠近自动连挂、速度预判或额外制动。待锁定时移开车辆会取消连接，避免隔空锁定。

## 物理约束

相同端点登记、配对存档和关节底层可以复用，各类型分别选择开始承载时机、名义长度、受压下界和松量。链销款设计销距 0.375 格、松量 0.0625 格；螺旋款设计钩距 0.65 格、松量 0.025 格；自动钩设计轴承距 1.125 格，允许 ±0.03125 格缓冲。旋转保持自由。

拉向弹簧在松弛时关闭；靠拢时限制阻尼，保证阻尼不会反向推车。进入有限行程前仍由原有有界弹簧收拢，不瞬移车体。旧 Railway 连接重新计算机械作用点和设计长度，本模组旧车钩仍保留旧规则。

## 原生外观与动画

在资源重载时读取安装的 Railway 原 JSON 和原纹理，用模型自带的 body_and_pin、link、knuckle、flat_links、screw、shackle 分组区分活动件，再按部件缓存烘焙；不复制外部资产进发布包。独立车钩、普通横梁、仿制横梁及翻转款共 25 个原生模型变体。

仅在物理体上的车端硬件启用动态显示：静态模型保留横梁和材质部分，活动硬件由独立渲染器接管，避免双重模型。物品栏、世界静态方块和原版 Train 装饰部件保留原生显示。染色取 Railway 原染色纹理，仿制材质保留原模型处理。

每一对只显示一个工作的连接环或螺旋组件，另一端保持备用组件；LINKLESS 仅在操作期间显示工具提供的连接环。连接环保持原生刚性尺寸，不用旧的伸缩杆动画代替。

## 保存与验证

操作起始时间、方向和时长随原 BlockEntity 保存并同步，重新进入不重播完整连挂过程。旧格式仍可读取。动画只描述机械过程，不新增轮子或车钩刚体。

已增加纯逻辑检查：销未落下不能承载、钩舌未闭合不能落锁、先挂环再旋紧、拉向阻尼不推车、加载时间进度有界。另有发布资产脚本验证 25 个变体的原分组、销形状和纹理。

## 客户端验收

1. 分别用 LINK、LINKLESS、KNUCKLE、KNUCKLE_SPLIT、SCREWLINK 连挂，观察每类动作；静止和连接过程中存档重进
2. 链销抬销时移开车、自动钩尚未闭锁时移开车，确认不会隔空锁定；螺旋式观察挂环后再旋转
3. 推拉运行，检查松弛连接不会自己推车；螺旋式配侧缓冲板，观察受压接触
4. 原生横梁材质、染色、翻转、物品栏与原版 Train 显示回归，确认没有原模型与动态件重叠
5. 过弯观察自动钩摆转、连接环跟随，离开视野边缘和重新加载区块不留悬空部件
6. 两个本模组原车钩、不同型拒绝、扳手转向/拆除、轨旁连挂与整列动力回归

限制：动态部件的显示与原固定碰撞近似并非逐面刚体铰接；螺旋组件和环的准确挂接位置、渲染剔除、Sable 网格与原生材质组合仍需要客户端观测。自动检查不能宣称视觉验收完成。

## 0.1.56 几何修正

自动钩原模型的钩舌位于 Z=3～5 像素，独立安装座轴承 Z=14 像素。旧轴承距 20 像素会让两只闭合钩舌占据同一体积；改为 18 像素后，两只钩舌纵向相邻。横梁款整体前移 3 像素，采用相同轴承间距。10 个自动钩模型变体均有原资产几何回归检查。

连挂双方以轴承连线和投影后的平均上方向建立互相对应的显示坐标。头部显示固定 18 像素间距，车体实际间距的微小变化由各端最大 0.125 格的钩柄显示行程吸收，安装座不移动。越过显示行程仍可能分离，不用无限拉长模型掩盖异常。链销连接环保持原尺寸，改为以原模型环中心对齐两销中点，替代绕单侧销摆放。

物理体碰撞从安装 Beta 的 JSON 元素生成并按方块朝向旋转；缓冲板保留板面、支杆和横梁。旋转元素取变换后的包围盒，平面装饰不产生零厚度刚体。自动钩的活动头和链环、螺旋活动件不作为固定阻挡盒，自动钩保留后部套座，传力仍由已有连接关节负责；玩家碰撞保留全部有体积的原模型元素。这是部件包围盒近似，不是活动零件的逐面刚体碰撞。形状按方块状态缓存，不在每帧解析。

新连挂及旧格式迁移时检查端点水平 3 格、垂直 1 格范围内、同物理体且同朝向的 Railway 小/大缓冲板及缓冲横梁。仅横向投影实际重合的缓冲部件参与压缩间距计算，面间预留 0.005 格。螺旋式允许在原长度上增加最多 0.25 格，链销式最多 0.0625 格，自动钩最多 0.25 格；超过硬件可达行程的安装拒绝连挂，避免约束和碰撞一直互相顶住。连挂后增减缓冲硬件应重新连挂以重新计算，暂不增加缓冲器压缩动画。

硬限位仅在车辆已经处于该类型自己的工作行程内、相对速度较小时捕获，避免套用旧的 0.1 格行程突然收紧。旧机制版本自动重算一次间距；若旧安装的缓冲板导致无法达到正确间距，则解除该连接并记录原因，不循环创建冲突约束。本模组 STANDARD 车钩仍使用既有长度和行程。

本次验收重点：自动钩连挂闭合、低速推拉和曲线晃动；普通/翻转/仿制横梁；小/大缓冲板正面接触和倒车分离；螺旋式加侧缓冲板；保存重进后长度及连接关系。客户端结果由用户观测确认。
