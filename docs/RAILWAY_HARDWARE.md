# Railway 车钩与缓冲板适配（0.1.54）

锁定 Steam ’n’ Rails NeoForge 0.3.0-beta.2。

## 使用

装在物理车体上的 Link & Pin 各款，以及普通/仿制车头横梁的 LINK、LINKLESS、KNUCKLE、KNUCKLE_SPLIT、SCREWLINK 款，统一使用本模组的车钩连接工具依次右击两端连挂，再右击已连接端解挂，重复右击所选端取消选择。扳手保留原生转向，潜行扳手保留拆卸。同型车钩才能连挂：本模组标准款与 Railway 款不互通，Railway 五种款式之间不互通；同款不同颜色、材质、独立/横梁安装形式可以互通。轨旁连挂器同样遵守类型限制及已有距离、空闲端点、低速等条件。

小/大缓冲器及横梁 PLAIN/BUFFER 款只提供碰撞。潜行扳手、染色和换材质沿用 Railway 操作，静态世界上的车钩仍保留原本普通扳手操作。连接工具在创造物品栏提供，生存配方为安山合金、铁锭、木棍各一个。本轮只支持物理车之间连挂。

## 实现与边界

保留原方块、BlockEntity、模型与材质。原生选择形状成为 Sable 碰撞形状和生物碰撞形状，跟随朝向、款式及上下翻转，不产生额外物理体。

现有连挂状态抽为 CouplerEndpoint。本模组车钩保留原顶层 NBT 字段；Railway 在原方块实体的 GuidedCoupler 子标签保存端点 UUID、锚点、固定长度及显示数据。配对仍在原 CouplerSavedData 中。卸载暂停关节但保留配对，破坏断开，物理结构移动保留锚点，同体合并解除自连接，复制端点沿用重复 UUID 检查。

设计长度由两端各自的模型伸出长度相加，保留 ±0.1 格伸缩和自由转向，不以点击时的距离或角度锁定。双本模组车钩仍为 1.46 格。

保留 Railway 静态外观，不增加钩头摆转和开闭动画；本模组活动车钩模型能识别 Railway 对端。两端 Railway 车钩的视觉间隙仍待实测。转向或改变款式时先解除既有连接，防止旧锚点与新外观不符。不支持原版 Train 与物理车混合连挂。

## 验证及客户端清单

完整离线 build 通过，新增混合设计长度和工作行程检查，并核对发布包的原生 read/write、款式与形状接口。构建及接口检查不替代实际 Mixin 应用和物理测试。

1. 两辆物理车各装 Railway 车钩，用连接工具连挂、解挂、再次连挂，测试正反向及过弯；扳手应只转向
2. 不同款式及本模组/Railway 混连应提示类型不同；同款独立车钩/横梁车钩应可连挂；检查固定间距、伸缩、主驾驶台及整列动力
3. 五种车钩、普通/仿制横梁及翻转款，纯缓冲款不应被当作连挂端点，染色换材质有效
4. 大/小缓冲器的玩家碰撞及物理车相撞，低速不穿透，倒车可分离
5. 保存重进、卸载恢复、拆除已连接端、粘合移动、复制及同体合并，检查残留约束
6. 轨旁连挂器识别 Railway 端点，并回归本模组原车钩和原版列车装饰部件

不自行启动测试服务器，客户端观测后结合日志决定下一步。

连接工具使用三维钳形物品模型，复用 Create 金属、黄铜和深色材质；只在物理结构上建立连挂，不参与原版 Train 组装。
