# 截图专用服务端场景

启动：`gradlew.bat -Pshowcase runShowcaseServer --offline`。

开发实例位于忽略目录 `run/showcase-server`，与原有客户端存档分离。本机已配置 Minecraft 1.21.1 超平坦世界（地面 Y=63）、创造模式、和平难度和端口 25566。首次在另一台机器使用时，需要先在该目录配置服务端、世界生成设置与 EULA；推荐仅监听本机地址。

生成代码位于 `src/showcase`，仅由显式 `-Pshowcase` 加入开发运行，并由截图服务端的系统属性启用。普通构建和发行 JAR 不包含此生成器；普通服务端和客户端不生成场景。

## 场景

- 主线：X=0，Y=65，Z=-80 至 80。机车在 Z=0，货车在 Z=10。
- 车辆通过生产代码的实际转向架放置流程生成；车体分属独立物理体，车钩使用实际连挂和关节。机车有铜色机罩、驾驶台与车棚，货车有箱子、木桶和储罐；初始使用安装座制动停车。
- 站台：轨道东侧 X=3 至 9，包含灯柱、铜色顶棚和原生车站；两端信号与车站行为绑定真实轨道。没有安装或伪造自动驾驶时刻表，不能把静态画面当作自动运行验收。
- 部件展示：轨道西侧，约 (-8,66,0)，提供独立驾驶台与车钩近景。

玩家加入后设为创造模式并放置到 (11,68,-12)，发放连接工具、扳手、转向架、驾驶台、护目镜和空白时刻表。可飞行取景；F1 隐藏 HUD，F2 保存原始截图。若修改过键位，以实际绑定为准。

服务端出现 `SHOWCASE_READY` 表示真实放置、连挂及保存步骤完成。场景标记保存后，重启不会重复建造；不要在普通存档启用此开发生成器。
