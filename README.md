# Create: Guided Railways 0.1.13

全新实现的轨道导向物理火车原型，优先验证自由造车与驾驶手感

## 环境与边界

Minecraft 1.21.1 / NeoForge 21.1.228 / Create 6.0.10-280 / Sable 2.0.3 / Java 21
只复用已有工程的构建环境，不包含旧轮轨物理、原生补丁或参考项目的实现代码
直接读取机械动力原版轨道网络，不新增轨道、轨道碰撞体或 Create Train 实体
原版直轨与贝塞尔弯轨用于导向；道岔已有前轴选路、后轴跟随的初步实现，尚无玩家主动选路、信号、跨维度或移动轨道支持

## 使用

1. 新建创造模式测试世界，从“导向铁路原型”物品栏取出“物理导向转向架”
2. 拿转向架对准机械动力直轨或弯轨中段右键，可从侧面或上方选择；服务端检查前后连续轨道长度
3. 顶部平面是车体安装座，可搭建方块，中心顶部接入机械动力旋转
4. 扳手右键安装座或转向架切换制动；潜行扳手拆卸，或创造破坏任一组件拆除整副；生存用镐拆除并返还转向架物品
5. 拿转向架右键已有物理车体底部安装，不要求附近有轨道；安装后用扳手选择离轨转向架，再对准目标轨道右键，将整节车上轨
6. 可以把多个顶部安装座所属车体粘合，转向架下部各自保持独立；不要把下部转向架也粘进车体
7. 脱轨后扳手右键选择，再右键目标轨道重新上轨；同车体多副会先验证整节车的方案，无法容纳则不移动

## 车钩使用

车钩装在物理车体两端，手持机械动力扳手操作

- 扳手依次右键两个车钩连挂，点击同一个未连接车钩取消选择
- 扳手右键已连接的车钩解开，潜行扳手拆卸车钩
- 钩头距离最多 2 格、高差最多 1 格，无需严格相向或左右对齐
- 允许低速连挂：各车体速度与两者相对速度均不超过 2 格/秒，角速度不超过 1.5 rad/s
- 一节车有动力即可拉动另一节车，车钩不跨车体传递 Create 应力网络
- 重新上轨前先解开车钩，避免单节传送牵扯其他车体
- 已有连挂工具作为兼容物品保留，但不再出现在创造栏或合成配方中

## 运动模型

每副独立安装时只有两个物理体：可扩展的上部车体安装座、下部转向架。共用车体时为一个车体加 N 个转向架
每个转向架通过两个轨道采样点与静态世界建立导向关节，沿轨道方向自由，不直接修改前进位置或速度
枢轴固定竖向支承和侧倾，偏航只加纯阻尼；单副固定俯仰，共用车体多副时允许有限俯仰以通过坡道接续
动力按目标速度误差施加有上限的牵引冲量，不模拟独立旋转轮体，轮子显示调用 Create 的标准转向架渲染 API
输入为零时施加可配置的滑行阻力，另有独立服务制动；固定动力下，载重增大后加速变慢
轨道缺失或导向点超出可捕获范围时解除导向；另有可配置的急弯与侧撞出轨，当前默认关闭

默认满输入 256 RPM 的目标为 12.8 格/秒，每 RPM 对应 0.05 格/秒
最大加速度 2.5 格/秒²，最大制动减速度 4 格/秒²，单副最大牵引力 abs(RPM)×6
共用车体的载重按已注册转向架数平均分摊；应力系数为单副承担质量 / 32，Create 再乘输入转速计算应力负载
本地开发客户端的实际参数文件为 run/config/guidedrailways-server.toml

## 0.1.4 碰撞范围与模型对齐

- 原型原来用单个 1.75×0.5×2.4 格碰撞盒，未覆盖完整车架、车轮、轴端；相向碰撞会先穿入外伸模型
- 改为固定的复合碰撞形状：车架主要构件、前后轮组及轴端，共 16 个逻辑盒，统一使用渲染偏移和车架缩放；实际原生盒数由 VoxelShape 合并/切分后决定，启动时 BogieCollision 日志记录
- 前后轮缘旋转包络长约 2.973994 格，轴端总宽 2.375 格；车架顶部、下部轮缘与前后端都纳入碰撞范围
- 轮子盒采用静态旋转包络，不随轮子动画重建，也不添加独立物理体或原生补丁；仍为一个车体加每副一个转向架刚体
- 19147 项资源几何断言读取实际 Create 模型，检查车架全部顶点、前后轮组 64 个转动相位的顶点都在简化碰撞范围内，并检查底部高于原版轨道 2/16 格物理碰撞面；原有 1108 项控制及路径检查仍通过
- 碰撞是简化盒体近似，不是逐三角网格，细小孔洞和曲面边缘存在保守包络；需要用户验证实际碰撞接触位置

客户端场景：两副在直轨上低速正面相撞、侧面相撞、斜向轻碰；观察轮缘、端部和上部是否仍明显穿过，再检查过弯是否受影响。旧存档已穿插的两副请先拉开。未运行专用服务器或自动驾驶。

## 0.1.5 完整碰撞占位与踏面接触高度

0.1.4 的模型外轮廓检查没有覆盖 Sable 默认烘焙器的逐方块裁剪。RapierVoxelColliderBakery 会把每个碰撞盒坐标裁到 [0,1]，因此仅把中心方块的 VoxelShape 扩大并不能实现完整碰撞。这是该版本碰撞仍过晚的明确缺陷。

- 按 Create bogey_frame.obj 的连通网格构件分解，去重后 21 个车架构件，加上前后轮组和轴端包络，共 27 个逻辑碰撞盒
- 将每个盒与所在方块逐格相交，使用中心实体块及相邻隐藏碰撞块，各块的局部坐标均在 [0,1]；运行日志记录实际占用格数及合并后的碰撞盒数
- 所有碰撞块在同一个转向架 SubLevel 内，零额外刚体、零额外关节；隐藏块无方块实体、无独立轮子渲染，质量为 0，原转向架质量保持 80
- 已有转向架载入时自动补齐碰撞占位；若占位处已有玩家方块，不覆盖这些方块，也不会强行启动该副导向
- 模型八角踏面在转动时的支承高度约 0.387426～0.41934685 格。原先按最大外接半径定高会产生约 0.032 格可见空隙；改用最小踏面接触高度，避免悬空，轮缘允许正常伸到轨顶以下，八角边缘存在轻微保守嵌入
- 改为 19228 项资源/裁剪检查：车架顶点和前后轮组 64 相位顶点都必须落在逐格裁剪后的形状内，所有格内盒不得越出 [0,1]；原 1108 项动力/轨道检查仍通过

整体是构件盒与轮组旋转包络的近似，不是逐三角碰撞。原生逐格接触效果需客户端实际验证；未运行专用服务器或自动驾驶。

本轮场景：拉开旧存档中已经穿插的两副，直轨低速正碰、侧碰、斜向碰撞；查看端部、车轮和轴端是否仍明显穿过；观察轮子静止/转动、直轨/弯轨/坡道贴合，最后确认转弯没有卡住。

- 21155 项碰撞断言通过，包括 Create 模型顶点、64 个轮转相位、圆周覆盖、方角排除、踏面与轮缘半径分离及格内裁剪。279 项动力与 829 项路径断言通过

## 0.1.7 断电滑行阻力

原代码零输入直接返回零牵引力，没有滚动阻力；当前导向允许纵向自由滑行，断电后的减速主要依靠 Sable 阻尼。日志可见每秒速度约下降 9%，低速尾段因此很长

- 新增配置 coastDeceleration，默认 0.6 格/秒²，仅在零输入且未使用主动制动时施加反向滑行阻力；设 0 恢复原先自由滑行
- 按各副分担质量计算阻力，避免载重或转向架数量直接倍增减速度；每步以剩余纵向动量为限，防止阻力导致倒退
- 保持原主动制动和有动力牵引规则；这是滑行阻力，不是坡道驻车锁定，也不抹除物理速度
- 纯控制检查覆盖不同质量、步长、正反向及低速停车，碰撞和轨道几何检查均通过；未运行专用服务器或自动驾驶

手动测试：64/256 RPM 直线断电、反向断电、停车后重新起步、空载与载重对比；客户端观测后再判断是否需要调整默认阻力


## 0.1.8 可调出轨机制初版

- 默认启用急弯超限和侧向撞击检测；轨道中断沿用原有释放导向行为，并统一持久化状态
- 使用实际纵向速度平方乘局部横向曲率估算横向加速度；坡道竖向曲率不作为横向弯道。根据车体与转向架质量加权的当前重心高度缩放风险，多副车体质量按数量分担
- 风险比 = v² × 横向曲率 × max(0.75,重心高度) / (derailLateralAcceleration × 1.5)。这是可调的游戏判据，不是完整的真实轮轨接触或侧翻求解
- 默认横向加速度基准 12 格/秒²，超限暴露积累 0.25 秒触发；恢复安全后暴露按两倍速度衰减，滤除短暂超限。参考重心高度 1.5 格时，12.8 格/秒通过 R16 风险约 0.85，R8 约 1.71
- 侧撞检测使用前后轮轴点速度，包括角速度项，避免正常偏航被当成侧撞；残余横向速度超过 4 格/秒持续 0.075 秒、或超过 8 格/秒立即释放。它检测残余运动，不保证检测到已被原生关节完全吸收的碰撞冲量
- 触发后整副转向架同时解除两根轨道导向，保留车体枢轴、位置、线速度与角速度，无额外甩飞力；停止轨道牵引及滑行阻力，后续由 Sable 碰撞和重力处理
- 下部刚体保存 GuidedDerailed 状态，重载或安装座重组后不自动吸回轨道。初版没有扳手重上轨，拆除重放可恢复；其他转向架各自判断
- 配置：derailmentEnabled、derailLateralAcceleration、derailOverloadSeconds、derailImpactSpeed。关闭可选机制不恢复已脱轨的车辆，轨道缺失仍会解除导向
- 日志增加 curveRisk、lateralSpeed，出轨事件记录原因、风险、速度及暴露时间
- 340 项纯出轨判据检查覆盖曲率、正反向、坡道区分、正常/超限速度、重心、时间过滤和侧撞；动力、碰撞和轨道检查通过。尚未驾驶验证，无专用服务器或自动驾驶测试

手动场景：直线/缓弯无误触发；同一急弯低速/高速与高重心载重对比；轨道尽头、侧向撞击；脱轨自由碰撞、保存重载、不自动回轨；拆除重放恢复


## 0.1.9 整节车上轨验证与反向选路
